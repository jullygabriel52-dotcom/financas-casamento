# Finanças 360 & Gestão do Casamento 💍

Sistema financeiro completo com controle mensal de contas, projeções de fluxo de caixa e gestão dos contratos do casamento.

### 🚀 Acesso Online:
- **GitHub Pages:** https://jullygabriel52-dotcom.github.io/financas-casamento/
- **Deploy no Vercel (1 clique):**

### 📌 Funcionalidades:
- **Gestão do Casamento:** Acompanhamento dos 16 fornecedores/contratos (Total: R$ 73.860,35 | Pago: R$ 21.749,35 | Restante: R$ 52.111,00).
- **Contas do Mês:** Controle de vencimentos, filtros por status e baixa de pagamentos com 1 clique.
- **Projeções 2026/2027:** Fluxo de caixa com linha do tempo de quitação das dívidas.
- **Persistência:** Salva automaticamente no navegador (`localStorage`) com suporte a exportação e importação de backup.
